# OSS Health and Wellness Team Working Agreement

This repository is for members of the OSS Health and Wellness team.

## Member instructions

1. Clone this repository:

   ```bash
   git clone https://github.com/mudabs/oss_team_working_agreement.git
   cd oss_team_working_agreement
   ```

2. Create a new branch for your signed agreement:

   ```bash
   git checkout -b your-name-signed-agreement
   ```

3. Open `Health_and_Wellness_Team_Working_Agreement.pdf`, sign it, and save the signed copy in this folder.

4. Commit and push your branch:

   ```bash
   git add Health_and_Wellness_Team_Working_Agreement.pdf
   git commit -m "Add signed health and wellness agreement"
   git push -u origin your-name-signed-agreement
   ```

5. Open a pull request from your branch so the team can review it.

Replace `your-name-signed-agreement` with a branch name that identifies you. Do not commit private information beyond what is required by the agreement.
